# Ingredient Tracking Terminal App

## About
This is a small side-project where I built a ingredient/pantry tracking program to help me to remember what is in my fridge and the expiry dates!

## Features
### Ingredient
- Add ingredient (Name, Category, Unit of measurement)
- Remove ingredient
- Update ingredient
- List all ingredients
### Pantry
- Add pantry item (Amount based on unit of measure of respective ingredient, Expiry date)
- Remove pantry item
- Update pantry item
- List all pantry items
### Recipes (Potentially in the future)
- Add recipes that have multiple ingredients
- "Cook" recipes that will use what is available from pantry
- Show you what you are able to cook or any ingredients you are missing from the pantry

## What I used
- rust
- rusqlite as the database
- dialoguer for terminal interaction
